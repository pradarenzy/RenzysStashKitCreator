This installs Renzy’s Stash Kit Maker into your Applications folder.

It is a local-only tool for mining the external samples referenced by FL Studio projects and building clean, deduplicated stash kits. Nothing is uploaded and no project file is ever modified — analysis is read-only and a kit is only written after you explicitly approve the build.

Requires an Apple silicon Mac running macOS 13 or later. The .NET runtime is bundled; you do not need to install anything else.
